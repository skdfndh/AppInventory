# 卸载能力实施安排

当前源码为 1.1 预览版，不替换已经发布的 v1.0.0。日常电脑不运行动态验收；完整检查仅在 GitHub 托管的临时 Windows 环境执行。

## 当前范围

| 能力 | 实现状态与边界 |
| --- | --- |
| 桌面 EXE/MSI 卸载 | 独立预检、精确注册表身份、命令与摘要复核、名称确认、单次权限选项；不默认静默或自动重启 |
| 当前用户 MSIX 卸载 | 完整包身份，阻止系统、框架、资源及被依赖的目标；不手动处理 WindowsApps |
| 安装目录残留 | 仅原始安装目录，明确选择后同盘隔离；摘要、共享目录、个人目录、链接及不覆盖恢复保护 |
| 当前用户配置 | 仅只读候选、明确选择、加密备份与备份核对；不修改注册表 |
| 注册表重命名与写回 | 已从实现移除，不通过测试夹具绕过；旧备份和隔离记录保留，但不自动恢复 |
| 跨盘关联及便携候选 | 保持只读，不按名称执行清理 |
| 服务、驱动、计划任务、永久删除 | 不在本版范围 |

## 已实现的保护

- 本次安装身份与标准命令单独读取，不使用静默入口替代；快照和 JSON 不能注入执行授权。
- MSI 只接受严格产品代码，调用系统卸载器并禁止自动重启。EXE 阻断脚本宿主、相对路径、网络路径、歧义命令及过长启动路径。
- 风险确认与精确应用名称缺一不可；执行前重新读取记录、卸载器和独立主程序摘要，签名按离线结果展示。
- 全局与任务互斥覆盖卸载、目录隔离及恢复；停止等待不会终止厂商卸载器，后台仍保留锁并核验。
- 成功退出码还需独立证据；失败、取消、缺少结果、证据变化、3010/1641 均不直接授权清理。重启时序当前仅有合成检查。
- 配置候选要求名称、路径、实际位置、完整读取与当前用户所有权证据；原键和值不变，备份值不进入明文报告。
- 每项检查完成和危险阶段开始前刷新进度文件，中断后可保留最后阶段；进度只含合成检查名称及时间。

## 隔离验收与发布门槛

CI 在 Windows Server 2022 和 2025 的临时实例运行随机身份 EXE、用户级及机器级 x86/x64 MSI、Inno 用户级专用包、签名 MSIX 和配置只读备份检查。仅创建和回收本次夹具，不操作已有软件；不上传真实清单、配置值、转储或未验收下载包。服务器版本通过不等同于 Windows 10/11 桌面兼容。

仍需完成：

- Windows 10/11 干净桌面环境、真实界面、UAC 取消和系统重启验收。
- 更多 Inno/NSIS 厂商安装器、真实交互及权限、占用和异常中断组合；专用静默夹具不等于完整厂商兼容矩阵。
- 注册表清理替代方案的独立设计与验证；在此之前不重新开放写入。
- 全部发布门槛核验后再决定是否发布卸载版本，不承诺所有软件兼容或找全全部残留。

本机仅执行 `dotnet build .\app-inventory\AppInventory.csproj -c Release`。不要设置 CI 环境变量绕过自检保护。结果与环境边界见 [uninstall-validation.md](uninstall-validation.md)。
