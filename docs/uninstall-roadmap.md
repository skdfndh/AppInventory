# 卸载能力实施安排

当前状态覆盖下文实现记录：注册表写入兼容性仍需排查，生产配置隔离与恢复暂时关闭。完整自检仅在独立 CI 执行，不在日常电脑复现。历史检查通过不构成正式发布或跨系统兼容结论。

当前源码为 1.1.0-preview.1，不替换已经发布的 v1.0.0。桌面 EXE/MSI 和当前用户商店包已有独立确认的执行入口；目录及满足证据条件的 HKCU 配置支持可恢复隔离。便携目录删除、机器级配置和永久删除未开放。测试只能使用本工具新建的专用应用或隔离环境，不对开发电脑现有软件试卸载。

## 流程与边界

已实现的桌面流程为：选择应用 → 重新读取安装身份 → 只读预检 → 用户确认本次目标和命令并输入应用名称 → 调用系统或厂商卸载器 → 独立核对结果 → 原安装目录残留预览 → 用户选择整个目录 → 同盘隔离及不覆盖恢复。尚不提供按文件挑选或跨盘复制隔离。

先完成交互式单应用卸载，不默认静默、不默认批量、不自动重启。普通卸载失败或取消后，不进入残留处理；成功退出码也不能单独证明卸载成功。厂商卸载器可能派生子进程，不复用实验室中终止测试进程树的做法。

本程序不保证回滚厂商卸载操作。隔离恢复仅还原明确隔离的文件或已备份的当前用户配置，不能恢复安装状态、服务、驱动和所有系统设置。商店移除由 Windows 管理包数据，不提供 WindowsApps 或包用户数据恢复。

## 第一阶段：普通软件只读预检

- [x] 从当前 BCU 注册表枚举结果定位记录，用只读句柄分别读取原始 UninstallString 与 QuietUninstallString。
- [x] 展示入口类型、记录范围、注册表路径、两个原始命令及阻断原因，不执行或修改命令。
- [x] 保留 NoRemove 限制；缺少标准命令时不回退静默命令。便携、商店和历史记录分别提示后续处理方式。
- [x] 卸载字段不保存到快照或 JSON 导出，恢复后必须刷新；合并历史测量不得覆盖本次读取的命令。
- [x] 合成检查覆盖静默入口、受保护记录、历史恢复、伪造 JSON、界面只读字段和刷新合并；真实枚举仅输出统计。

本阶段“已读取”只证明字段可读，不证明命令安全、数字签名可信或能够正常卸载。计算机级记录只能提示可能需要管理员权限，不能据此判断实际权限。

## 第二阶段：命令校验与结果状态（仍只在专用测试应用执行）

- [x] 桌面身份包含注册表根、32/64 位视图和精确子键；名称与目录不充当身份。
- [x] MSI 核验产品代码、当前已安装状态和登记身份，使用系统 msiexec，将 /I 转为 /X 并禁止自动重启；EXE 拆分完整路径与原始参数。
- [x] 不通过命令解释器执行系统记录；脚本宿主、URL、相对/网络路径、歧义引号与 MSI 附加属性阻断。
- [x] 执行前重读完整安装快照及摘要；离线签名结果展示供确认，不联网补证书，不将未核验视为可信。
- [x] 单任务文件互斥、执行日志和明确的单次权限选项；停止等待不强杀卸载器，后台保留互斥并继续核验。
- [x] 独立结果状态，3010/1641 不立即授权清理；历史缺少退出结果不补报成功。重启时序只完成合成检查，实际重启待隔离验收。
- [x] 专用组件覆盖换命令、换文件、中文空格路径、失败、假成功、停止等待和子进程提前退出；保留旧实验室白名单。
- [ ] 真实 UAC 取消、计算机级提权及权限不足交互在隔离环境验收。

验收门槛：没有有效本次确认就无法启动进程；所有异常状态均禁止清理；日志中不记录令牌、完整私人目录清单或无关软件详情。

## 第三阶段：虚拟机兼容性矩阵与正式入口

- [x] 利用现有 GitHub Actions 临时 Windows 虚拟机实际验证机器级 MSI 和专用签名 MSIX，不在开发电脑代替验证。
- [ ] 准备可恢复快照的 Windows 10/11 x64 桌面虚拟机，补齐跨版本、交互和真实重启验收。
- [x] 自建 x86/x64 MSI 均实际安装与卸载；专用 EXE 在中文空格路径下验证，安装目录外哨兵保持完整。
- [x] 桌面卸载同时核对精确安装记录及主程序/MSI 产品状态，退出码不能单独授权清理。
- [ ] 常见厂商 NSIS/Inno、计算机级提权、Windows 10 与其他 Windows 11 构建的兼容矩阵。
- [x] 商店卸载单列适配，使用完整包身份，仅限当前用户；阻断系统包、框架、资源及被其他包依赖的目标，随机身份 MSIX 已在临时 Windows CI 实际安装和卸载。
- [x] 已验证的基础 EXE/MSI 流程进入本地预览版，界面阻断不支持的入口；v1.0.0 标签与附件不变。
- [ ] 隔离环境矩阵通过后再正式发布卸载版本，不将预览版等同于完整兼容验收。

## 第四阶段：残留与可恢复隔离

- [x] 复用 BCU 精确安装目录扫描；文件清单和 SHA256 只作为内容未变化的证据，不将目录候选宣传为全部可删除。
- [x] 名称匹配和跨盘关联不进入隔离；残留默认不选择，系统/个人/同步目录和与其他安装记录重叠的目录被阻止。
- [x] 仅同盘移动确认的原安装目录；包含链接或不可完整读取时拒绝。预览后文件或空目录变化会废止确认；恢复不覆盖，隔离及恢复中断可复核。
- [x] HKCU 配置键要求 BCU 名称、安装路径、实际位置、当前用户所有权及完整读取证据；预览后独立选择，先 DPAPI 加密备份，再同父键重命名隔离。值、权限或目标变化阻止覆盖；隔离副本丢失后可从备份恢复。明文报告不含配置值。
- [x] 专用配置实际验证嵌套键、原始环境变量、全部支持的值类型、权限恢复、冲突、篡改与完整暂存恢复；服务、驱动、任务和永久删除不纳入本版范围。
- [ ] 虚拟机验证共享目录、同名应用、联接替换、文件占用、断电中断和跨盘隔离，确认个人数据哨兵完整。
