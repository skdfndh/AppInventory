# 第三方组件与修改说明

本应用复用 Bulk Crap Uninstaller 的 UninstallTools 和 KlocTools，原项目由 Marcin Szeniak 等贡献者开发。

- 原项目：https://github.com/Klocman/Bulk-Crap-Uninstaller
- 本地基线提交：30da609384c98ba6e35c6530129541ea4ff3970a
- 原许可证和 NOTICE 随附在本目录，原作者不负责本应用的非官方修改版本。

本项目对核心库进行了界面依赖拆分：移除 ObjectListView 依赖、排除核心内的界面目录、将必要提示与删除处理交由宿主接入、调整部分 COM 调用与后台异常处理。仓库根目录的 bcu-core.patch 保存完整差异，Initialize-Dependencies.ps1 固定上游版本并核对补丁。

常规软件清单仅使用已核对的安装记录读取入口，没有配置通用文件删除处理器，没有面向现有软件的卸载或残留清理入口。1.0 保留独立专用测试窗口，复用 BCU 的卸载调用和安装目录扫描，只接受本工具新建的白名单测试会话，残留使用本项目受控移动与恢复。WPF 界面、便携候选扫描、本地快照和报告导出由本项目实现。

Windows 自包含发行包附带 Microsoft .NET 运行时组件；相应第三方说明以发行包中随附文件为准。
